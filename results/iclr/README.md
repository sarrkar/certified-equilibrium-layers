# Project 1 (ICLR): identifiability results

Generated artifacts (JSON + figures only, no prose paper; see CLAUDE.md rule 7).

## How to reproduce

```bash
python experiments/iclr/run_identifiability_synthetic.py --seed 0
```

Writes `identifiability_synthetic.json` and `identifiability_synthetic.png`.

## What it measures

Concept latents Z are generated by a latent linear SCM, mixed by the KNOWN
invertible propagation operator `P_alpha` (reused from `cascade.verify.containment`)
and an unknown map `G`, then recovered from interventional data. The latent mean
correlation coefficient (MCC, 1 = identified up to permutation and scaling) and
the Amari distance of the recovered mixing are reported per regime:

- `independent_hard`: the identifiable base case (independent sources, single-gene
  hard interventions). MCC is near 1.
- `dense_hard`, `soft_combinatorial`: open research targets. The current
  rank-one covariance-difference recovery does not yet identify these; see the
  xfail-strict marker in `tests/test_identifiability.py`.
